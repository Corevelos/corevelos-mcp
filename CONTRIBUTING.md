# Contributing

Open an issue or pull request with a minimal reproduction using dummy credentials and a mock API. Keep customer data and secrets out of fixtures and logs. Include a regression test for behavior changes. Contributions are accepted under Apache License 2.0.

For a maintainer checkout of the canonical repository, run `git config --local core.hooksPath .githooks` to enable the push destination check. The check expects `origin` to point at `Shujaatali786/corevelos-mcp`. Forks use their own remotes and can leave this checkout-specific hook disabled.
